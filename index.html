synergy-rates

Structured JSON of Synergy's (WA electricity retailer) published plan pricing — scraped from their own public plan pages, since they publish no API for it. Unofficial; see the repo for how and why.

Endpoints

All plans, or one plan by slug — plain JSON, CORS enabled:

curl https://m-rk.github.io/synergy-rates/data/plans.json
curl https://m-rk.github.io/synergy-rates/data/plans/midday-saver.json

Slugs match the end of Synergy's own plan URLs, lowercased (e.g. midday-saver, home-plan-a1). The full list is the plans[].slug field in data/plans.json, or the current plans rendered below.
